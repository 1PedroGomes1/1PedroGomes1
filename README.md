## 📌 Principais projetos

### 🌱 Agrelp - Sistema de Gerenciamento Agrícola

Sistema web desenvolvido para auxiliar no gerenciamento de uma propriedade rural, permitindo o controle de máquinas, ferramentas, sementes, materiais, defensivos agrícolas e informações gerais por meio de dashboard.

**Tecnologias utilizadas:** Java, Spring Boot, Thymeleaf, HTML, CSS, JavaScript, Bootstrap, JPA e banco de dados relacional.

🔗 Repositório: [agrelp-sistema-gerenciamento-agricola](https://github.com/1PedroGomes1/agrelp-sistema-gerenciamento-agricola)
